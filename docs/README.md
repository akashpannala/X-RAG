# X-RAG documentation

Documentation is organised with [Diátaxis](https://diataxis.fr): four document types, four distinct jobs.

| Type | You want to… | Document |
|---|---|---|
| Tutorial | learn the product by doing it | [tutorial.md](tutorial.md) |
| How-to guide | get a specific job done | [how-to.md](how-to.md) |
| Reference | look up facts (API, env vars, CLI) | [reference.md](reference.md) |
| Explanation | understand how and why it works | [explanation.md](explanation.md) |

Elsewhere in the repo:

- [README.md](../README.md) — project entry, quickstart, logos
- [SPEC.md](../SPEC.md) — product spec, 20-layer map, deploy matrix
- `/docs` on a running server — interactive Swagger UI
